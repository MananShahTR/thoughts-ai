# ThoughtLogger 📝

A beautiful, intuitive thought logging app that helps you capture daily reflections and discover patterns in your thinking.

## ✨ Features

### 🖊️ Thought Logging
- **Clean, distraction-free interface** for writing thoughts
- **Mood tracking** with visual indicators (positive, neutral, negative)
- **Tag system** for organizing thoughts by themes
- **Auto-save** to local storage for data persistence
- **Daily statistics** showing your writing streak and progress

### 🔍 Theme Analysis
- **Intelligent theme extraction** using client-side NLP
- **Sentiment analysis** to understand emotional patterns
- **Category classification** (emotions, activities, people, places, concepts)
- **Time-based filtering** (week, month, quarter, year)
- **Visual trend indicators** showing rising/falling themes
- **Frequency analysis** with beautiful progress bars

### 🎨 Design
- **Glassmorphism UI** with subtle animations
- **Responsive design** that works on all devices
- **Beautiful color palette** with calming blues and greens
- **Smooth transitions** powered by Framer Motion
- **Accessibility-first** design with proper contrast and keyboard navigation

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd thought-logger

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Building for Production

```bash
# Build the app
npm run build

# Preview the production build
npm run preview
```

## 🧠 Theme Analysis Algorithm

The app uses sophisticated client-side NLP to analyze your thoughts:

1. **Keyword Extraction**: Removes stop words and identifies meaningful terms
2. **Phrase Detection**: Finds important 2-3 word phrases
3. **Emotion Recognition**: Matches against emotion word dictionaries
4. **Activity Pattern**: Identifies action words and patterns
5. **Sentiment Analysis**: Classifies themes as positive, neutral, or negative
6. **Frequency Analysis**: Counts occurrences and tracks trends over time

## 🔐 Privacy

- **100% Private**: All data stored locally in your browser
- **No Server**: No thoughts are ever sent to external servers
- **Offline Capable**: Works completely offline
- **Export/Import**: Your data belongs to you

## 🎯 Usage Tips

1. **Write Regularly**: Try to log thoughts daily for better pattern recognition
2. **Use Tags**: Tag your thoughts to help organize them by themes
3. **Check Insights**: Visit the themes tab weekly to see your patterns
4. **Export Data**: Regularly export your data as backup
5. **Be Honest**: The more authentic your entries, the better insights you'll get
